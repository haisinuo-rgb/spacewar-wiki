How to Use the Browser Emulator

  1. Open the emulator in your web browser: masswerk.at/spacewar
  2. Wait for the PDP-1 to boot — the emulator will load the Spacewar! paper tape automatically. You'll see the CRT display come to life with the star and two ships.
  3. Learn the keyboard controls — the emulator maps PDP-1 control box functions to keyboard keys. Check the emulator's documentation page for the exact key mapping (typically: Player 1 = A/D rotate, W thrust, Space fire, S hyperspace; Player 2 = J/L rotate, I thrust, K fire, U hyperspace).
  4. Start playing — both ships are active from the start. Player 1 controls the Needle, Player 2 controls the Wedge. Duel around the central star!
  5. Adjust settings — most emulators let you adjust CRT phosphor persistence, display scaling, and speed. Experiment to find the most authentic (or most playable) settings.

📝 Emulator Tip

The original PDP-1 ran at approximately 100 kHz — much slower than modern computers. Some emulators run at full PDP-1 speed (which can feel slow), while others offer speed adjustment. If the game feels sluggish, look for a speed or throttle setting in the emulator controls.

Steam Version (AppID 480)

On Steam, there is a game called "Spacewar" with AppID 480. This is not the original 1962 PDP-1 game — it is a test/demo application created by Valve for Steamworks developers to test multiplayer, achievements, and other Steam features.

Key facts about Steam's Spacewar:

  • Developer: Valve Corporation
  • AppID: 480
  • Cost: Free (but not listed in the Steam Store — must be added via console command or developer tools)
  • Purpose: Test application for Steamworks SDK
  • Gameplay: Simplified 2D space shooter, not the original PDP-1 Spacewar!
  • Controversy: Frequently used by game pirates to disguise cracked games as "Spacewar" in the Steam library

Modern Remakes & Homages

Over the years, many developers have created modern remakes and spiritual successors to Spacewar!. These capture the core gameplay — two ships, a gravity well, torpedoes, hyperspace — while adding modern graphics, sound, and quality-of-life features.

Spacewar! (HTML5 Remakes)

Several developers have created HTML5/JavaScript remakes of Spacewar! that run directly in the browser. Search for "spacewar html5" or "spacewar javascript" on GitHub and itch.io. These typically feature modern controls and sometimes online multiplayer.

Free Browser

Star Control (1990)

Created by Toys for Bob and published by Accolade, Star Control is a direct spiritual successor to Spacewar! It features the same core "ship vs ship with gravity" combat, expanded with multiple ship types, each with unique weapons and abilities, plus a strategic meta-game.

Retro PC

Asteroids (1979)

Atari's Asteroids, created by Ed Logg and Lyle Rains, was directly inspired by Spacewar! It features the same vector graphics aesthetic and inertia-based movement, but replaces the two-player duel with a single-player survival mode against asteroid fields and UFOs.

Arcade Classic

Gravitar (1982)

Another Atari game inspired by Spacewar!, Gravitar emphasizes the gravity mechanics even more strongly. Players navigate a ship through solar systems with realistic gravity, landing on planets to complete missions. A cult classic that's notoriously difficult.

Arcade

Oids (1987)

Developed by Dan Hewitt for the Atari ST and later ported to other platforms, Oids is a gravity-based shooter that owes a clear debt to Spacewar! Players rescue enslaved "Oids" from enemy bases, using thrust and gravity to navigate treacherous planetary surfaces.

Retro

Modern Indie Titles

Search itch.io, Steam, and GitHub for "spacewar," "gravity duel," or "vector combat" to find modern indie takes on the formula. Many are free or low-cost, and some feature online multiplayer, custom ship editors, and tournament modes.

Running on Original PDP-1 Hardware

If you happen to have access to a working PDP-1 (there are approximately 3-4 known working machines in museums and private collections), you can run the original Spacewar! from a paper tape. The Computer History Museum in Mountain View, California, has a restored PDP-1 that regularly demonstrates Spacewar! to visitors.

The original game was distributed as a paper tape — a long strip of paper with holes punched in it representing the PDP-1 machine code. To load it, you would:

  1. Mount the Spacewar! paper tape on the PDP-1's tape reader
  2. Toggle in the bootstrap loader on the front panel switches
  3. Start the tape reader to load the game into memory
  4. Jump to the program start address
  5. Connect the custom control boxes and begin playing

The entire loading process takes about 30-60 seconds — lightning fast for 1962, when loading a program from tape could take minutes.

System Requirements

  • RAM: 512 MB free

Original PDP-1 (1962)

  • Computer: DEC PDP-1 minicomputer
  • Memory: 4K–9K words (18-bit each)
  • Display: Type 30 CRT, 1024×1024
  • Storage: Paper tape reader
  • Input: Custom control boxes (2×)
  • Power: ~1.5 kW (needs dedicated circuit)
  • Cooling: Air-conditioned room recommended
  • Cost: $120,000 (1962 USD) — if you can find one
  • Footprint: ~2×4 feet of floor space
